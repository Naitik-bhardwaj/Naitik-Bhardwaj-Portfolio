# Naitik Bhardwaj — Portfolio

A responsive personal portfolio built with **HTML, CSS and vanilla JavaScript**.

## Highlights
- Modern dark UI with responsive layout
- Mobile navigation menu
- Scroll reveal animations
- Resume download
- Project and certificate sections
- GitHub and LinkedIn profile links
- Accessible semantic HTML and reduced-motion support

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive styling and animations
- `my.png` — profile image
- `resumenew.pdf` — resume
- `Certificates/` — certificates

## Run locally
Open `index.html` with VS Code Live Server, or open the file directly in a browser.
